# BuildSmith

A desktop application for automated replication of development and DevOps environments across machines.

## Overview

BuildSmith scans your existing computer to extract installed tools, configurations, and settings, then creates a portable bundle that can be used to recreate your development environment on any other device.

## Features

- Scan and export development tools, configurations, and settings
- Portable, encrypted bundles for secure environment migration
- Automated setup on new devices
- Support for Docker images, VS Code profiles, database connections, and more
